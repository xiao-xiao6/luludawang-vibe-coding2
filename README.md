## 🎯 游戏简介

淘气鬼们钻进菜园啦！你有一把锤子和 **60 秒**，把冒头的目标统统敲回去。

游戏在经典打地鼠的基础上做了不少加法：

- 🎨 **完全手绘感的美术**：所有目标都是原创贴图（WebP 内联），配天空、太阳、飘云、蝴蝶的装饰场景
- 🔊 **零音频文件的全合成音效**：全部用 Web Audio API 现场合成，没有一个大体积音频资源
- 🏆 **完整的成长线**：积分 → 买锤子 → 换画风 → 冲成就 → 上排行榜
- 📱 **手机 / 平板 / 桌面全适配**：从 360×640 的超小屏到 1920×1080 的超宽屏都测过
- ♿ **认真的无障碍**：键盘全流程可玩、屏幕阅读器播报、减少动效模式
- 📦 **单文件交付**：一个 HTML 走天下，不依赖任何 CDN、不需要构建步骤

## 🕹 核心玩法

| 项目 | 说明 |
|------|------|
| **单局时长** | 60 秒 |
| **场地** | 12 个洞口（响应式网格，桌面 4 列 / 手机 3 列） |
| **操作** | 鼠标点击 / 手指触屏 / 键盘方向键 + 空格 |
| **计分** | 打中目标得分 → 连击倍率加成 → 结算模式加成 → 转化为积分 |
| **失误惩罚** | 打中陷阱目标（桃桃）扣分；漏掉目标不算失误但会断连击 |
| **暂停** | 支持暂停 / 继续；切到后台自动冻结倒计时，不会偷跑时间 |

### 三种交互方式

1. **鼠标 / 触屏**：直接点冒头的目标，锤子光标会跟着你走并挥下去
2. **键盘**：`方向键` 移动洞口高亮框，`空格` / `回车` 敲下去（设置面板里有「试试看」引导）
3. **触屏优化**：`touch-action` 已处理，不会误触发页面滚动或双击缩放

## 🎚 难度模式

三档难度不只是改数字，从刷怪节奏、目标停留时间、陷阱密度到评级门槛都是独立调过的。

| 参数 | 🍃 简易 | 🌸 普通 | 🔥 困难 |
|------|--------|--------|--------|
| **积分倍率** | ×0.6 | ×1.2 | ×2.4 |
| **结算加成** | +80 | +220 | +520 |
| **刷怪间隔** | ×1.75（更慢） | ×1.0 | ×0.66（更快） |
| **目标停留** | ×1.75（更久） | ×1.0 | ×0.62（极短） |
| **陷阱密度** | ×0.35（稀少） | ×1.0 | ×1.4（成堆） |
| **难度爬升** | 0.45 | 1.0 | 1.55 |
| **双目标概率** | 5% | 35% | 75% |
| **狂热触发** | 6 连击 | 10 连击 | 14 连击 |
| **S 级门槛** | 420 分 | 1500 分 | 2600 分 |

> 三档的场地配色也做了区分：简易更亮暖、普通中性、困难偏深，一眼能分辨当前难度。

**节奏设计**：难度随时间线性爬升 —— `difficulty = min(1, 已用时间 / 55 × 模式系数)`，也就是最后 5 秒永远是全场最紧张的时刻。进入狂热时间后刷怪间隔再 ×0.75。

### 特殊目标详解

**👑 噜噜大王（彩蛋）**
- 登场时会有全屏闪光 + 三重涟漪 + 星屑 + 专属音效
- 停留时间走独立的 `eggUp` 参数，不受难度压缩影响，三档都能从容点到
- 打中固定 **+300 分**，是单局最高单体收益

**🎁 惊喜礼盒（随机奖励）**
拆开后三种结果等概率：
1. 直接加分（20 × 模式倍率）
2. **下 3 秒分数 ×2**（爆发窗口）
3. **清空场上一个危险目标**（救命用）

**👑 噜噜大王の王冠（精英怪）**
- 血量 3 点，需要连点三次才能击破
- 只在**最后 15 秒**登场，每局最多 2 只，出现概率 28%

**🍑 桃桃（陷阱）**
- 打中 **−30 分** + 果汁四溅特效 + 屏幕震动
- 不只靠颜色区分，还带**形状角标**，色盲玩家也能辨认

## 🔥 连击与狂热时间

连击是这游戏的核心爽点。

### 连击窗口

每打中一次目标刷新连击计时，**窗口 2.2 秒**。连击条会实时显示剩余时间，超时归零。

### 连击倍率

| 连击数 | 倍率 |
|--------|------|
| 5 – 9 | **×2** |
| 10 – 14 | **×3** |
| 15+ | **×5** |

### 狂热时间

连击数达到当前难度的门槛（简易 6 / 普通 10 / 困难 14）后自动触发：

- 🟠 场地边框亮起橙色描边
- 💓 整个游戏框脉动发光
- ⚡ 刷怪间隔 ×0.75，节奏全面加速
- 🎵 专属音效

连击一断，狂热立刻结束 —— 保持手感就是一切。

## 📖 首次启动引导

第一次打开（或从旧版本升级到新版）时，会在首页之上弹出一个**三步静态操作说明**：

1. **点它一下** —— 点击或触摸冒头的地鼠就能击打

| 行为 | 规则 |
|------|------|
| 首次访问 | 弹出一次 |
| 关闭后刷新 | 不再弹出（`wmz_guideSeen` = `true`） |

| 清除存档后 | 重新回到首次引导 |

### 画风 → UI 主题联动

目前有**三套跟随画风自动切换**的 UI 主题（其余画风一律保持经典田园 `classic`）：

| 画风 | 前置条件 | UI 主题 | 观感 |
|------|----------|---------|------|
| ⚙️ 蒸汽画风 | 整套解锁 + 正在使用 | `steampunk` | 铜铁深棕 + 黄铜高光 + 硬边框 / 铆钉感 |
| 👾 像素可爱风 | 整套解锁 + 正在使用 | `pixelcute` | 奶油底 + 棕描边 + 明亮叶绿，8px 方角，星露谷半像素味 |
| 🖌 水墨画风 | 整套解锁 + 正在使用 | `inkwash` | 宣纸米白 + 淡青绿水彩晕染 + 朱砂红按钮，中文楷体题字，边缘柔和 |

以**像素可爱风**为例：整套解锁并切到该画风后，整套界面（首页、HUD、连击条、面板、tab、卡片、按钮、结算页、toast）连同**场地贴图**与**页面背景**一起切换；它的实现与蒸汽朋克完全同构，同样遵守下面的规则。

- **整套**拥有 + 正在使用 → 切换；只买单张、或装备了该画风但未拥有整套 → **不切换**（保持经典田园主题）
- 切回原版二次元或其他画风 → 立即回到经典主题
- **没有独立的主题开关**：主题是「拥有整套 + 当前使用」的纯派生结果，不新增存档键、不升存档版本
- 主题只改 **颜色 / 背景 / 圆角 / 描边 / 阴影**，不改字号、尺寸与动效；主题属性 `data-ui-theme` 落在 `<body>` 上，默认 `classic`
- **字体是唯一的额外例外**，且只在水墨 / 像素两套主题里放开 `font-family`：水墨用系统中文楷体栈（`STKaiti / Kaiti SC / KaiTi / 楷体 / Songti SC / SimSun`，不新增字体文件）；像素用内嵌的 OFL 像素字体子集（见「素材与许可」）。经典 / 蒸汽两套主题不写任何字体声明，渲染结果与改造前逐像素一致
- 首屏由一段极小内联脚本按存档预置主题（`body` 后第一段脚本，映射表与应用脚本里的 `UI_THEME_BY_STYLE` 两处同步），避免刷新时闪一下经典配色
- 场地贴图通过 `--field-grass / --field-hole-back / --field-hole-front` 三个 URL 变量切换（这是「局内表现层不接 token」约定里唯一的明确例外，只换贴图来源，不参与尺寸计算）
- **页面背景**同样跟随主题：经典态用 `bg1` + 50% 白色遮罩，蒸汽态用 `bg2` + 50% `#5B5B5B` 遮罩，像素态用 `bg3` + 50% 白色遮罩，水墨态用 `bg4`（水墨淡彩风景）+ 30% 宣纸米白遮罩；四张图都放在 `art/bg/`，通过 `--ui-page-bg` 一处切换
- 像素态刻意**保留**天空 / 太阳 / 云 / 蝴蝶 / 漂浮作物装饰（`--ui-decor-display:block`），只把圆角从 18~26px 收到 8px，美观性不换来 playability 损失；水墨态反过来把装饰全部收起（`--ui-decor-display:none`），保持宣纸干净，圆角维持柔和的 22 / 18 / 16px
- 像素 / 水墨态所有文本对底色均按 WCAG 配平（正文 / 数值 ≥4.5:1，大字 / 图标 / 边框 ≥3:1），语义色仍保留色相区分：难度三档（紫 / 绿 / 红）、稀有度、危险红、金银铜
- 页面背景只铺在游戏卡片外围的留白层，卡片、面板、覆盖层保持不透明；背景按 `cover` 居中裁切，不参与布局、不捕获点击

## 🛠 技术栈

| 层面 | 选型 | 说明 |
|------|------|------|
| **结构** | 原生 HTML5 | 无框架，语义化标签 + ARIA |
| **样式** | 原生 CSS3 | Grid / Flex / 自定义属性 / 动画 / 媒体查询 |
| **逻辑** | 原生 JavaScript (ES5+) | 无构建步骤，无模块打包 |
| **动画** | [GSAP 3.13.0](https://gsap.com) | 内联引入，用于补间动画与时间轴 |
| **音效** | Web Audio API | **全部实时合成**，零音频文件 |
| **贴图** | WebP + Base64 内联 | 56 张图全部内嵌，单文件自包含 |
| **存储** | localStorage | 本地存档，不上传任何数据 |
| **PWA** | Service Worker + Manifest | 可安装到桌面 / 支持离线游玩 |

### 为什么是单文件？

- **零部署成本**：一个文件丢上去就能跑，不用配 CDN、不用管跨域
- **绝对离线**：没有网络请求就没有加载失败，断网照样玩
- **易于分享**：发给朋友一个 HTML 文件就能玩

代价是首屏体积较大（约 1.1MB），但换来的是**打开即玩、永不缺资源**。

### 音效是怎么做的？

所有音效都用 `OscillatorNode` + `AudioBuffer`（白噪声）+ `BiquadFilter` 现场合成：

```js
// 敲击音：噪声 + 下滑音调
whack: function(){
  noise(t, 0.07, 0.32, 1100);       // 带通滤波白噪声
  tone('sine', 240, 70, t, 0.12, 0.36);  // 240Hz → 70Hz 下滑
}
```

共 **17 种音效**：敲击、命中、星星、错误、爆炸、果汁、倒计时、连击、号角、失败、购买、装备、陷阱、礼盒、彩蛋、精英、事件。全部通过一条 master gain 总线统一控制音量。

## ❓ 常见问题

<details>
<summary><b>为什么文件这么大？</b></summary>

为了做到「单文件自包含」。56 张贴图以 Base64 内联在 HTML 里，占了约 88% 的体积。

这是刻意的取舍：换来零依赖、零请求、绝对离线。如果更在意体积，可以把贴图拆成独立文件，但那样就失去了「一个文件走天下」的优势。
</details>

<details>
<summary><b>数据会上传到服务器吗？</b></summary>

**不会。** 所有数据只存在浏览器 `localStorage` 里，项目没有任何后端、没有埋点、没有统计代码。清除浏览器数据就会重置。
</details>

<details>
<summary><b>换了浏览器存档就没了？</b></summary>

是的，存档绑定在浏览器上，不跨设备同步。换设备 / 换浏览器会重新开始。
</details>

<details>
<summary><b>手机上能离线玩吗？</b></summary>

可以。首次打开后 Service Worker 会缓存全部资源，之后断网也能正常游玩。添加到主屏幕后体验接近原生 App。
</details>

<details>
<summary><b>可以用键盘玩吗？</b></summary>

完全可以。游戏进行中用 `方向键` 移动选中框，`空格` 或 `回车` 敲下去。首页和各个面板都可以用 `Tab` 遍历、`Enter` 激活、`Esc` 关闭。
</details>

<details>
<summary><b>觉得动画太多、有点卡？</b></summary>

首页 → **设置** → 打开**低动效模式**，会关闭装饰动画并减少粒子效果。系统层面开启「减少动效」也会被自动识别。
</details>

<details>
<summary><b>怎么改难度？</b></summary>

首页有三张难度卡片（简易 / 普通 / 困难），点击切换，选择会被记住。三种难度的评级门槛和积分倍率完全不同，困难模式单局收益是简易的 4 倍。
</details>

<details>
<summary><b>积分怎么花？</b></summary>

首页 → **工坊**。可以买锤子（纯外观）或者画风包。所有锤子都不影响游戏平衡，纯手感与视觉享受。
</details>
